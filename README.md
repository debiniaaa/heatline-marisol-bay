HEATLINE: Marisol Bay — an original open-world crime game that plays in the browser. Explore the sun-soaked city of Marisol Bay on foot and by car: steal cars, run a three-mission story and courier jobs, fight, and outrun a five-star wanted system with police who respond. Keyboard and mouse, no build step, fully offline.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
